# demorcleak

**DEMORCE** media tools — static site for GitHub Pages.

- Discord avatar / banner download (by user ID)
- Spotify cover art (oEmbed)
- Pinterest + Cobalt media fetch
- Client-side GIF studio (image + video frame strip)

## Live

Enable **Settings → Pages → Deploy from branch → main / root**.

URL: `https://hexed00.github.io/demorcleak/`

## Local

Open `index.html` or any static server:

```bash
npx serve .
```
